## 🚀 Featured Projects

### 🔥 [Liner Cementing Job Calculator](https://github.com/CamelCod/liner-cementing-job-calculator)
**Advanced well construction planning tool with AI-powered analysis**

A production-ready TypeScript/React application for drilling engineers to design and optimize liner cementing operations.

**Key Features:**
- 📐 Comprehensive torque & drag modeling (soft-string mechanics)
- 🎯 Packer setting force simulation and safety factor calculation
- 🧮 Real-time cement job volume calculations
- 🤖 AI-powered analysis with Gemini integration
- 📊 3D well path visualization with interactive charts
- 📄 Professional PDF report generation with jsPDF

**Tech Stack:** TypeScript, React, Remotion, Gemini AI, Lucide Icons

---

### 📚 [CFD Tutorial in Julia](https://github.com/CamelCod/A-CFD-Tutorial-in-Julia)
**Computational Fluid Dynamics: Laminar Boundary-Layer Theory**

Published research code repository demonstrating numerical solutions to fundamental fluid dynamics problems.

**Features:**
- Blasius, Hiemenz, Homann, and Falkner-Skan flow equations
- Finite difference scheme implementation
- Thomas algorithm for linear system solving
- Comparative analysis with published data

**Publication:** *Oz, F.; Kara, K. A CFD Tutorial in Julia: Introduction to Laminar Boundary-Layer Theory. Fluids, 2021.*
